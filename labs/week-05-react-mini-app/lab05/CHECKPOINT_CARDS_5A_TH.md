## กติกา

- แก้เฉพาะ TODO ของ CP ปัจจุบัน อย่าข้ามไปทำของ CP ถัดไป
- หลังแก้ทุกครั้ง รัน `npm run dev` แล้ว `npm run check -- --session=1`
- รายการที่ขึ้น `[SKIP]` คืองานของคาบ 5B ยังไม่ต้องทำ
- ติดที่เดิมเกิน 10 นาที ให้ยกมือ — มีทางลงเตรียมไว้ให้แล้ว
- ต้องอธิบายโค้ดของตัวเองได้ ถ้าใช้ AI ช่วย ต้องบันทึกใน `AI_USAGE.md`
