คำถาม Checkpoint ทำไม checker ผ่าน 133/133 ไม่ได้แปลว่างานเสร็จ
คำตอบที่ต้องการ — checker ตรวจโครงสร้างและพฤติกรรมของ Service ได้ แต่ตรวจไม่ได้ว่าหน้าจอแสดงผลถูก คีย์บอร์ดใช้ได้ หรือของเดิมจาก Week 04 ยังทำงาน

Exit ticket 4 ข้อ

✓1. readStoredRequests() คืนสถานะได้ 3 แบบ — แต่ละแบบเกิดเมื่อไหร่
✓2. ทำไมต้องตรวจข้อมูล 3 ชั้น ทั้งที่เกณฑ์เหมือนกัน
✓3. เราเปลี่ยนจาก seed เป็น storage โดยแก้กี่บรรทัด และทำไมถึงน้อยขนาดนั้น
✓4. Week 06 เราจะสร้าง Express API — ไฟล์ไหนใน React app นี้จะเปลี่ยนมากที่สุดเมื่อถึง Week 08
