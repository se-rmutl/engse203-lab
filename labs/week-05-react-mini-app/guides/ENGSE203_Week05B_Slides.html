MISCONCEPTION 04 ผมจะเขียนผิดให้ดู

ทายก่อน — จะได้อะไรกลับมา

localStorage.setItem('test', { name: 'สมชาย' });
localStorage.getItem('test');   // → ?

สามประเด็นที่ต้องเห็น
  • เบราว์เซอร์แปลง object เป็นข้อความให้เอง แต่แปลงแบบไร้ประโยชน์
  • ข้อมูลข้างในหายหมดและกู้กลับไม่ได้
  • ไม่มี error ใด ๆ โปรแกรมทำงานต่อเงียบ ๆ แล้วรู้ตัวตอนอ่านกลับไม่ได้

Local Storage เก็บได้แต่ข้อความ — ต้องแปลงเองเสมอ ด้วย JSON.stringify ตอนเก็บ และ JSON.parse ตอนอ่าน
