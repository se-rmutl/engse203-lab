Equivalence partitioning

แบ่งค่าที่เป็นไปได้เป็นกลุ่มที่ระบบควรทำแบบเดียวกัน · ทดสอบตัวแทนกลุ่มละ 1 ค่า

Boundary value

กฎ "อย่างน้อย N" → ทดสอบ N−1 · N · N+1 เสมอ · bug ชอบซ่อนตรงขอบ

กฎ: รายละเอียดอย่างน้อย 10 ตัวอักษร — ชุดค่าไหนจับ bug ที่ขอบได้

บทที่ 2 / 9 · ออกแบบ test case ลองเล่น — เลื่อนความยาว แล้วสลับโค้ด

ค่าขอบจับ <= ได้ · ตัวแทนกลุ่มจับไม่ได้

โค้ดใน validator:

โค้ดให้ผ่าน โค้ดปฏิเสธ ผลไม่ตรงสเปก ค่าขอบ 9 · 10 · 11 · คลิกช่องได้

บทที่ 5 / 9 · Integration test ต่อยอดจาก W07 · W10

supertest ยิง HTTP โดยไม่ต้องเปิดพอร์ต

import request from 'supertest';
import { createApp } from '../../src/app.js';
import { loadSeed } from '../../src/services/requestService.js';

const app = createApp();
beforeEach(async () => { await loadSeed(); });  // ฐานข้อมูลใหม่ทุกข้อ

test('PUT เปลี่ยนสถานะ → 200', async () => {
  const r = await request(app).put('/api/requests/REQ-001')
                              .send({ status: 'completed' });
  expect(r.status).toBe(200);
  expect(r.body.status).toBe('completed');
});
// api/vitest.config.js
test: {
  env: {
    DB_FILE: ':memory:',
    NODE_ENV: 'test',
  },
}

:memory:

ฐานข้อมูลใน RAM · loadSeed() ทุกครั้งได้ก้อนใหม่ 5 รายการ · ไม่แตะ campus.db

supertest รับ app ตรง ๆ ไม่ต้อง listen · starter มี GET/POST อยู่แล้ว 8 ข้อ — CP46 เพิ่ม PUT และ DELETE

บทที่ 5 / 9 · Integration test เห็นภาพ

beforeEach = ทุก test เริ่มจากสภาพเดียวกัน

ถ้าใช้ before (ครั้งเดียว) แทน beforeEach — test B ที่รันหลัง test A จะเป็นอย่างไร
