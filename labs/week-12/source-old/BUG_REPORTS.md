# รายงานปัญหาจากผู้ใช้ (Bug Reports)

ระบบนี้เปิดให้ทดลองใช้แล้ว ผู้ใช้แจ้งปัญหาเข้ามา 3 เรื่อง — **มีแต่อาการ ยังไม่มีใครรู้สาเหตุ**
งานของเราคือ ทำให้เกิดซ้ำ → หาสาเหตุด้วยเครื่องมือ → แก้ → เขียน test กันไม่ให้กลับมา

> บันทึกการไล่ปัญหาแต่ละเรื่องใน `DEBUG_LOG.md`

---

## BUG #1 · ลบคำร้องแล้วเพิ่มใหม่ ขึ้น error

**ผู้แจ้ง:** เจ้าหน้าที่ฝ่ายอาคาร

> "วันนี้ลบคำร้องที่ซ้ำไป 1 รายการ แล้วพอนักศึกษาส่งคำร้องใหม่ ระบบขึ้นว่า 'เกิดข้อผิดพลาดภายในเซิร์ฟเวอร์'
> เมื่อวานยังส่งได้ปกติ"

- เกิดทุกครั้งหรือไม่: ไม่ทุกครั้ง — เมื่อวานส่งได้ วันนี้ส่งไม่ได้
- หน้าจอที่เกิด: หน้า "สร้างคำร้องใหม่"

## BUG #2 · ตัวเลข "กำลังดำเนินการ" บน Dashboard เป็น 0 ตลอด

**ผู้แจ้ง:** หัวหน้าฝ่ายบริการ

> "การ์ดสรุปด้านบนบอกว่ากำลังดำเนินการ 0 รายการ แต่ในรายการด้านล่างเห็นคำร้องสถานะ in-progress อยู่
> ตัวเลขอื่นดูถูกต้อง"

- เกิดทุกครั้งหรือไม่: ทุกครั้ง
- หน้าจอที่เกิด: Dashboard

## BUG #3 · เปลี่ยนสถานะคำร้องที่เพิ่งถูกลบ ขึ้น error 500

**ผู้แจ้ง:** เจ้าหน้าที่ฝ่าย IT

> "เพื่อนร่วมงานลบคำร้องไปแล้ว แต่หน้าจอของผมยังค้างอยู่ พอผมกดเปลี่ยนสถานะ ได้ error 500
> น่าจะต้องบอกว่า 'ไม่พบคำร้อง' มากกว่า"

- เกิดทุกครั้งหรือไม่: ทุกครั้งที่เปลี่ยนสถานะคำร้องที่ไม่มีอยู่
- ทดสอบซ้ำได้ด้วย: `PUT /api/requests/REQ-999` พร้อม `{ "status": "completed" }`
