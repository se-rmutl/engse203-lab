①

รูปแบบพื้นฐานของ JOIN

แยกข้อมูลเป็น 2 ตารางเพื่อไม่ให้ซ้ำ — แต่เวลาใช้จริงต้องเห็นพร้อมกัน

SELECT r.id,
       u.name AS requesterName,
       r.status
FROM requests r
JOIN users u ON u.id = r.requester_id;
บรรทัดหมายความว่า
FROM requests rเริ่มจากตาราง requests · ตั้งชื่อย่อ r
JOIN users uเอา users มาต่อ · ตั้งชื่อย่อ u
ON u.id = r.requester_idเชื่อมตรงไหน — แถวที่ค่าตรงกัน
⚠ ลืม ON — เขียน FROM requests, users เฉย ๆ จะได้ทุกแถวจับคู่กับทุกแถว = 5×4 = 20 แถวไร้ความหมาย และไม่มี error บอก · ผลลัพธ์เยอะผิดปกติ → ตรวจ ON ก่อน
②

JOIN ร่วมกับ WHERE

กรองด้วยคอลัมน์จากตาราง users ได้ ทั้งที่เริ่มจาก requests

SELECT r.id, u.name, r.details
FROM requests r
JOIN users u ON u.id = r.requester_id
WHERE u.department = 'วิศวกรรมซอฟต์แวร์'
ORDER BY r.id;
③

งานของคุณ — เขียน 4 query

ลองเขียนเองทั้ง 4 ข้อ

ข้อเขียน query ที่
①แสดงคำร้องพร้อมชื่อผู้แจ้ง
②แสดงคำร้องพร้อมชื่อและภาควิชา
③กรองเฉพาะคำร้องของภาควิชาหนึ่ง
④ตั้งชื่อคอลัมน์ด้วย AS ให้ออกมาเป็น requesterName
คำใบ้ — เปิด queries.sql ที่ทำระหว่างคาบ คัดลอกมาปรับได้
⭐

สังเกตผลลัพธ์ข้อ ④ ให้ดี
