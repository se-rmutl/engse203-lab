## ใครเป็นเจ้าของงานไหน

| บทบาท | ข้อสอบ Part 1 (take-home) | ข้อสอบ Part 2 (ในห้อง) |
|---|---|---|
| **Front-end** | bug ฝั่งหน้าเว็บ · ฟีเจอร์ส่วนหน้าเว็บ · test ใต้ `frontend/` | เขียน code review (`REVIEW.md`) · change request ส่วนหน้าเว็บ · test ใต้ `frontend/` |
| **Back-end** (ทีมคู่: Back-end + DevOps) | bug ฝั่ง API 2 ตัว · ฟีเจอร์ส่วน API · test ใต้ `api/` · (ทีมคู่) ความลับ/secret | แก้ปัญหาตรรกะ · change request ส่วน API · test ใต้ `api/` · (ทีมคู่) แก้ปัญหาความปลอดภัย |
| **DevOps** (ทีม 3 คน) | ความลับ/secret · CI + วิธีรัน production (+10) | แก้ปัญหาความปลอดภัยใน PR |

```
คะแนนของคุณในแต่ละ Part (เต็ม 100) = 100 × (0.6 × % งานของตัวเอง + 0.4 × % ของทั้งทีม)   → × 0.05 = คะแนน A7 ส่วนนั้น
```

- ช่วยกันแบบ **pair programming** ได้ตลอด — เจ้าของงานเป็นคนพิมพ์ (driver) และ commit · เพื่อนที่ช่วยคิด (navigator) ใส่ `Co-authored-by:` ท้าย commit
- หลักฐานว่าใครทำอะไร: `team.json` · commit ของเจ้าของงาน · ช่อง "ผู้รับผิดชอบ" ใน `DEBUG_LOG.md` · "ผู้เขียน" ใน `REVIEW.md`
- **เจ้าของงานอธิบายงานของตัวเองไม่ได้ = งานนั้นของคนนั้นเหลือครึ่ง** (ไม่กระทบคะแนนส่วนตัวของเพื่อน)

- ทำ LAB 12–13 ให้เข้าใจ — Part 1 และ Part 2 ใช้ทักษะเดียวกัน (test · debug · validation · auth · secret)
