## A6 · ผลงานรายบุคคล (5 คะแนน)

| เกณฑ์ | เต็ม | ได้เต็ม | ได้ครึ่ง | ได้ 0 |
|---|---:|---|---|---|
| **I1** งานตามบทบาท | 2 | ทำครบรายการ "ต้องทำ" ใน [ROLES.md](ROLES.md) ของบทบาทตัวเอง | ครบ ≥ 60% | < 60% |
| **I2** หลักฐาน git | 1.5 | commit ในส่วนตัวเอง ≥ 10 กระจาย ≥ 5 วัน · PR merge ≥ 2 · review ≥ 1 | ครบบางข้อ หรือ commit กระจุกใน 1–2 วันสุดท้าย | แทบไม่มี commit ของตัวเอง |
| **I3** ประเมินจากเพื่อน | 1.5 | ค่าเฉลี่ยที่เพื่อนให้ ≥ 4 จาก 5 | 3 – 3.9 | < 3 (และหลักฐาน git สอดคล้อง) |

**กฎรายบุคคล**

- ไม่มีหลักฐานการทำงานใน git เลย → **A6 รายบุคคล = 0 และผลงานทีมได้สูงสุด 50%** (ส่วนของทีมไม่ได้มาจากคนนี้)
- อธิบายส่วนของตัวเองไม่ได้ในการสัมภาษณ์ → I1 = 0 (ถือว่าไม่ได้ทำเอง)
- ใช้ AI โดยไม่เปิดเผยใน README และอธิบายโค้ดไม่ได้ → I1 = 0 · ส่งเรื่องตามกติกาความซื่อสัตย์ทางวิชาการ
- ประเมินเพื่อนต่างจากหลักฐานมาก (เช่นให้เพื่อน 1 ทั้งที่เพื่อนมี commit มากที่สุด) → ผู้สอนไม่ใช้คะแนนนั้น
