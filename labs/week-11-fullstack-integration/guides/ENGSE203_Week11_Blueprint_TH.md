## 5. บท "อ่านเพิ่มเติม" — MongoDB และ async (ไม่ต้องลงมือ)

**เป้าหมาย** — ตอบ CLO5 ว่านักศึกษา "รู้จักทางเลือก" โดยไม่ต้องเขียนโค้ด

### เนื้อหา 1 บท ครอบคลุม

| หัวข้อ | อธิบายอะไร |
|---|---|
| SQL vs NoSQL | ตาราง/แถว vs collection/document · เมื่อไรเหมาะอันไหน |
| **ทำไมวิชานี้เลือก SQLite** | ข้อมูลเรามีโครงชัด · ความสัมพันธ์ชัด · SQL เหมาะกว่า |
| async คืออะไร | ถ้าฐานข้อมูลอยู่คนละเครื่อง (เช่น MongoDB Atlas) จะต้องรอเครือข่าย → ใช้ `await` |
| ไปเรียนต่อที่ไหน | วิชาฐานข้อมูลเทอมหน้า · แหล่งเรียน MongoDB |

> **หลักการ** — บอกให้รู้ว่ามีโลกที่กว้างกว่านี้ แต่ไม่บังคับให้เดินเข้าไปตอนนี้
> เหมือนหัวข้อ "สิ่งที่ยังไม่ได้ทำ" ใน DATA_MODEL.md ของสัปดาห์ 9

### คำถาม CP41 (ตอบจากบทอ่าน)

1. ทำไมโปรเจกต์นี้เลือก SQLite แทน MongoDB
2. ถ้าวันหนึ่งต้องเปลี่ยนไป MongoDB จะกระทบชั้นไหนบ้าง (คำใบ้: service + controller เพราะ async)
3. async จำเป็นเมื่อไร ไม่จำเป็นเมื่อไร
